# Deploy-FirefoxProfile

Links the repository's `Firefox/user.js` (Betterfox) into the default Firefox profile, or every
profile with `--all`, backing up a real `user.js` first.

## Configuration Keys

This command reads no `Unix/config` files. There is nothing to configure.

## Usage

```bash
Deploy-FirefoxProfile
Deploy-FirefoxProfile --all
Deploy-FirefoxProfile --check
```
