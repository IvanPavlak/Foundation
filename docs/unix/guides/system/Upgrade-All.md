# Upgrade-All

Upgrades the named package managers (Homebrew and the App Store by default, macOS updates only when named), listing and skipping the pinned Homebrew formulae.

## Configuration Keys

This command reads no `Unix/config` files. There is nothing to configure.

## Usage

```bash
Upgrade-All
Upgrade-All Homebrew
Upgrade-All Homebrew AppStore MacOS
Upgrade-All Homebrew,MacOS
```
