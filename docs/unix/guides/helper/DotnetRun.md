# DotnetRun

Runs the already built .NET project in the current directory (alias `dnr`); the arguments go to `dotnet run`.

## Configuration Keys

This command reads no `Unix/config` files. There is nothing to configure.

## Usage

```bash
DotnetRun
dnr --launch-profile MyProfile
```
