# NpmInstallAndStart

Installs the npm dependencies, then starts the project even when the install failed (as on Windows) (alias `nir`); the arguments go to `npm start`.

## Configuration Keys

This command reads no `Unix/config` files. There is nothing to configure.

## Usage

```bash
NpmInstallAndStart
nir -- --port 4200
```
