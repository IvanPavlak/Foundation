# GitSwitch

Switches to a local branch, or to `master` (or `main`) when none is given (alias `gsw`); a branch that exists only on `origin` is refused, as on Windows.

## Configuration Keys

This command reads no `Unix/config` files. There is nothing to configure.

## Usage

```bash
GitSwitch
GitSwitch feature/my-feature
gsw
```
