# Close-ProjectTerminals

Closes the WezTerm tabs titled `<Project>.*`, keeping the whole tab it runs in.

## Configuration Keys

This command reads no `Unix/config` files. There is nothing to configure.

## Usage

```bash
Close-ProjectTerminals MyProject
Close-ProjectTerminals MyProject MyOtherProject
```
