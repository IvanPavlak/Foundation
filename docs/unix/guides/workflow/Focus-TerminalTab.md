# Focus-TerminalTab

Brings the WezTerm window this shell runs in to the front.

## Configuration Keys

This command reads no `Unix/config` files. There is nothing to configure.

## Usage

```bash
Focus-TerminalTab
Focus-TerminalTab --quiet
Focus-TerminalTab --target-title MyProject.API
```
