# EfCoreMigrationWizard

Menu-driven Entity Framework Core migration manager for the nearest .NET solution (alias `efm`).

## Configuration Keys

This command reads no `Unix/config` files. There is nothing to configure.

## Usage

```bash
EfCoreMigrationWizard
efm
```
