# Git-Diff

Shows every change against `HEAD`, staged or not (`git diff HEAD`, alias `gdf`).

## Configuration Keys

This command reads no `Unix/config` files. There is nothing to configure.

## Usage

```bash
Git-Diff
gdf
```
