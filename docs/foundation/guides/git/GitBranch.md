# GitBranch

Lists every branch with its last commit, or creates a branch (alias `gb`).

## Configuration Keys

This command reads no `Unix/config` files. There is nothing to configure.

## Usage

```bash
GitBranch
GitBranch feature/my-feature
gb
```
