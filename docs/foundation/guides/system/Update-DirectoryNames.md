# Update-DirectoryNames

Renames every folder directly under a path whose name ends in `_YYYY_MM_DD` to end in today's date instead.

## Configuration Keys

This command reads no `Unix/config` files. There is nothing to configure.

## Usage

```bash
Update-DirectoryNames
Update-DirectoryNames ~/Documents/MyProject --dry-run
```
