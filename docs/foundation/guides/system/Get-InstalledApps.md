# Get-InstalledApps

Writes the installed Homebrew formulae and casks, App Store apps and application bundles to `installed_apps.txt` on the Desktop.

## Configuration Keys

This command reads no `Unix/config` files. There is nothing to configure.

## Usage

```bash
Get-InstalledApps
Get-InstalledApps --output ~/Documents/installed_apps.txt
```
