# List-AvailableColors

Prints the terminal's colour palette: the 16 ANSI colours with their SGR codes, then the 256-colour palette as numbered swatches.

## Configuration Keys

This command reads no `Unix/config` files. There is nothing to configure.

## Usage

```bash
List-AvailableColors
```
